## 📖 项目简介

Home Assistant(core)是一个把**本地控制**和**隐私**放在首位的开源家庭自动化平台。它由全球 DIY 爱好者和折腾党社区驱动维护,非常适合跑在树莓派或本地服务器上,让智能家居数据留在自己家里,而不是上传到别人的云端。

## ✨ 主要特性

- **本地优先**:自动化逻辑与数据都在本地运行,不依赖厂商云服务
- **隐私优先**:智能家居数据掌握在自己手中,而非第三方公司
- **开源社区驱动**:由全球范围内的折腾爱好者与 DIY 社区共同开发维护
- **模块化架构**:系统采用模块化方式构建,轻松为新设备或新动作添加支持
- **树莓派友好**:完美适配 Raspberry Pi,也可运行在任意本地服务器
- **丰富集成**:官方维护大量设备与服务集成,覆盖主流智能家居生态
- **在线演示**:无需安装即可在浏览器中体验完整界面
- **完善的文档与教程**:从安装上手到自动化进阶、再到自定义组件开发,资料齐全

## 🚀 快速开始

1. **在线体验**:先访问官方演示站 [demo.home-assistant.io](https://demo.home-assistant.io),零安装感受完整功能
2. **安装部署**:按照官方安装指引 [home-assistant.io/getting-started](https://home-assistant.io/getting-started/) 选择树莓派、本地服务器等适合的安装方式
3. **学习自动化**:跟随官方教程 [home-assistant.io/getting-started/automation](https://home-assistant.io/getting-started/automation/) 创建第一个自动化场景
4. **查阅文档**:遇到问题先翻官方文档 [home-assistant.io/docs](https://home-assistant.io/docs/)
5. **深入了解架构**:开发者可阅读[架构说明](https://developers.home-assistant.io/docs/architecture_index/)与[自定义组件开发指南](https://developers.home-assistant.io/docs/creating_component_index/)
6. **加入社区**:通过 [Discord 聊天室](https://www.home-assistant.io/join-chat/) 与全球用户交流,遇到问题也可查看[帮助专区](https://home-assistant.io/help/)
